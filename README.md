## Projects

## Task 01: Hangman Game

A console-based word-guessing game developed using Python.

## Features

- Random word selection from an English word list.
- Displays hidden letters and reveals correctly guessed letters.
- Tracks guessed letters using sets.
- Allows up to six incorrect guesses.
- Displays Hangman stages and win/loss messages.
- Handles repeated guesses.

Technologies: Python, Random module, Sets, File and data handling.

## How to run

python hangman.py


## Task 02: Stock Portfolio Performance Tracker

A Python console application that helps users track stock holdings and calculate portfolio performance.

## Features

- Accepts stock ticker symbols, purchase prices, and share quantities.
- Loads stock symbols from a CSV dataset.
- Calculates investment value, market value, gains, losses, and percentage returns.
- Attempts to retrieve available stock prices using yfinance.
- Allows manual price entry when online price retrieval is unavailable.
- Exports portfolio holdings to a CSV file.

Technologies: Python, CSV, yfinance, urllib.

## How to run

Install the optional market-data library:

python -m pip install yfinance


Run the application:

python portfolio.py


Note: Market prices may be delayed or unavailable. Sample CSV files, if included, are provided for demonstration purposes.
