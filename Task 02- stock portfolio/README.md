# Stock Portfolio Performance Tracker

## Description
A Python console application that tracks stock investments and calculates portfolio value, gains, and losses.

## Features
- Loads S&P 500 ticker symbols from a CSV dataset.
- Accepts stock tickers, purchase prices, and share quantities.
- Retrieves market prices when it is available.
- Calculates investment value and percentage returns.
- Saves portfolio results to 'portfolio_summary.csv'. 

## Technologies
- Python 3
- CSV module
- yfinance library

## Dataset
https://raw.githubusercontent.com/datasets/s-and-p-500-companies/master/data/constituents.csv

## How to Run
Install the required package:

 bash
python -m pip install yfinance


Run the program:

 bash
python portfolio.py
